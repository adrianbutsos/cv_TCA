│  │ Nombre:       /^([A-Z][a-z]+(?:\s+[A-Z][a-z]+)*)/      │              │
│  │ LinkedIn:     /linkedin\.com\/in\/([a-zA-Z0-9-]+)/      │              │
│  │ Website:      /https?:\/\/(?:www\.)?[a-zA-Z0-9-]+/     │              │
│  │ Ubicación:    /([A-Z][a-zA-Z]+),\s*([A-Z]{2}|...)/     │              │
│  │ Puesto:       /(?:Senior|Junior|Lead|Manager|...)/     │              │
│  │ Bio:          /(?:summary|bio|about|overview).../i      │              │

================================================================================
PERFORMANCE ESPERADO
================================================================================

PDF pequeño (< 2MB)
├─ Parsing:     ~400ms (pdfjs-dist)
├─ Extracción:  ~100ms (regex)
├─ UI:          ~100ms (render)
└─ TOTAL:       ~500ms

DOCX pequeño (< 1MB)
├─ Parsing:     ~100ms (mammoth)
├─ Extracción:  ~100ms (regex)
├─ UI:          ~100ms (render)
└─ TOTAL:       ~200ms

Imagen (< 1MB)
├─ OCR:         ~2-5s (tesseract.js - procesamiento intensivo)
├─ Extracción:  ~100ms (regex)
├─ UI:          ~100ms (render)
└─ TOTAL:       ~2-5 segundos

Text (< 100KB)
├─ Parsing:     ~50ms (FileReader)
├─ Extracción:  ~50ms (regex)
├─ UI:          ~100ms (render)
└─ TOTAL:       ~100ms

================================================================================
SEGURIDAD Y PRIVACIDAD
================================================================================

En cada paso del flujo:

┌──────────────────────────────────────────────────────────────────┐
│ ✅ GARANTÍAS DE PRIVACIDAD                                       │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 1. Lectura del archivo                                          │
│    └─ FileReader API nativo del navegador                      │
│    └─ Data NUNCA sale del navegador                            │
│                                                                 │
│ 2. Parsing del archivo                                         │
│    └─ pdfjs-dist → Ejecuta en navegador                       │
│    └─ mammoth → Ejecuta en navegador                          │
│    └─ tesseract.js → Ejecuta en navegador                     │
│    └─ NINGUNA librería envía datos a servidores               │
│                                                                 │
│ 3. Extracción de datos                                         │
│    └─ RegEx patterns → Ejecutan en navegador                  │
│    └─ JavaScript puro → Sin llamadas a API                    │
│                                                                 │
│ 4. Almacenamiento                                              │
│    └─ extactedData se guarda solo en memoria                  │
│    └─ Se limpia cuando usuario cierra diálogo                 │
│    └─ localStorage NUNCA se utiliza                           │
│                                                                 │
│ 5. Envío de datos                                              │
│    └─ Los datos SOLO se usan localmente                       │
│    └─ Se pasan al formulario del usuario                      │
│    └─ El usuario decide qué guardar                           │
│                                                                 │
└──────────────────────────────────────────────────────────────────┘
