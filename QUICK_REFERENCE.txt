FLUJO DE DATOS:
─────────────────────────────────────────────────────────────────────────────

Usuario
  ↓
Carga archivo (drag/drop/click)
  ↓
FileUploadSection.processFile()
  ↓
parseFile(file)
  ├─ Detecta tipo
  ├─ Parsea según tipo (PDF/DOCX/TXT/IMG)
  └─ Retorna texto extraído
  ↓
extractAllData(text)
  ├─ Aplica regex patterns
  ├─ Busca: email, phone, name, etc
  └─ Retorna ExtractedData structured
  ↓
Muestra preview dialog
  ├─ Calcula confidence score
  └─ Muestra datos encontrados
  ↓
Usuario hace clic "Aplicar Datos"
  ↓
handleDataExtracted()
  ├─ Auto-llena campos en personal-info
  └─ Cierra preview

PATRONES DE REGEX:
─────────────────────────────────────────────────────────────────────────────

Email:
  /\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b/g

Phone (múltiples formatos):
  /(\+\d{1,3}[-.\s]?)?\(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}|.../ g

LinkedIn:
  /(?:https?:\/\/)?(?:www\.)?linkedin\.com\/in\/([a-zA-Z0-9-]+)/gi

Website:
  /https?:\/\/(?:www\.)?[a-zA-Z0-9-]+\.[a-zA-Z]{2,}(?:\/[^\s]*)*/gi

Location (City, Country):
  /([A-Z][a-zA-Z]+),\s*([A-Z]{2}|[A-Z][a-zA-Z]+)/g

Title (job positions):
  /(?:Senior|Junior|Mid-level|...)?\s*(?:Engineer|Developer|...)/gi

Formato        MIME Type                      Handler
─────────────────────────────────────────────────────────────────────────────

─────────────────────────────────────────────────────────────────────────────

SCORING DE CONFIANZA:
─────────────────────────────────────────────────────────────────────────────

> 70% = ✅ Alta (verde)
  ├─ Nombre encontrado
  ├─ Email encontrado
  └─ Mínimo 2 campos adicionales

40-70% = ⚠️  Media (amarillo)
  ├─ Algunos campos encontrados
  └─ Verificación manual recomendada

< 40% = ❌ Baja (rojo)
  ├─ Pocos o ningún campo encontrado
  └─ Verificación manual necesaria

─────────────────────────────────────────────────────────────────────────────

ERROR HANDLING:
─────────────────────────────────────────────────────────────────────────────

Errores comunes y soluciones:

1. "File is too large"
   └─ Máximo 50MB, reduce tamaño

2. "Failed to parse PDF"
   └─ Verifica que sea PDF válido

3. "Failed to parse DOCX"
   └─ Intenta en otro formato

4. "Failed to extract text from image"
   └─ Normal para imágenes, intenta con documento escaneado

5. OCR muy lento
   └─ Normal (1-5 segundos), es procesamiento local
