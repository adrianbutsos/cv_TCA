⚡ 5 MINUTOS DE SETUP

1. INSTALAR DEPENDENCIAS
   ├─ npm install     (NPM)
   ├─ pnpm install    (PNPM)
   ├─ yarn install    (Yarn)
   └─ Espera 2-3 minutos

2. RECARGAR NAVEGADOR
   ├─ F5 o Cmd+R (Mac)
   └─ Espera a que se recompile

3. PROBAR
   ├─ Ve al paso "Información Personal"
   ├─ Busca la sección "Importar Información"
   ├─ Carga un archivo PDF, DOCX, TXT o imagen
   ├─ Espera 1-5 segundos
   ├─ Revisa los datos extraídos
   └─ Haz clic "Aplicar Datos"

4. ¡LISTO!
   └─ Los campos se llenan automáticamente

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEMA: "Module not found: 'pdfjs-dist'"
SOLUCIÓN: npm install
          Espera 2-3 minutos y recarga

PROBLEMA: OCR muy lento en imágenes
SOLUCIÓN: Usa PDF o DOCX en lugar de imagen
          O usa imagen de mayor calidad

PROBLEMA: No extrae datos esperados
SOLUCIÓN: Intenta con otro archivo
          Verifica que el archivo sea válido
          Lee FILE_UPLOAD_GUIDE.md

PROBLEMA: El botón no aparece
SOLUCIÓN: Recarga la página (F5)
          Limpia cache (Ctrl+Shift+R)

PERFORMANCE
================================================================================

  PDF pequeño (< 2MB):    ~500ms
  DOCX pequeño (< 1MB):   ~200ms

PREGUNTAS FRECUENTES
================================================================================

P: ¿Dónde se guardan mis archivos?
R: En NINGÚN lado. Se procesan y se descartan.

P: ¿Funciona sin internet?
R: Sí, completamente local.

P: ¿Qué navegadores soporta?
R: Chrome 50+, Firefox 45+, Safari 10+, Edge 15+

P: ¿Puedo editar después de aplicar?
R: Sí, puedes ajustar manualmente cualquier campo.

P: ¿Por qué es lento con imágenes?
R: El OCR requiere procesamiento intensivo. Es normal.

P: ¿Puedo descargar mis datos después?
R: No se guardan automáticamente. Debes exportar del formulario.

P: ¿Es gratis?
R: Completamente gratis y de código abierto.

P: ¿Puedo usar datos sensibles?
R: Sí, todo se procesa en tu navegador.
